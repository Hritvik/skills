# Itinerary Builder

Construct one optimized itinerary per shortlisted destination. Cluster nearby activities, include transfers, parking, queues, meals, check-in/out, daylight, rest, and buffers. A two-night trip is not three full sightseeing days.

Respect opening hours, seasonality, booking requirements, traveller pace, accessibility, and weather sensitivity. Mark fixed commitments separately from flexible stops and include a compact fallback for weather-dependent days.

Do not generate relaxed/balanced/intensive variants for every option by default. Create variants only for finalists or on request. Return structured days, route legs, overnight base, estimated timing, cost item IDs, evidence IDs, and the principal compromise.
