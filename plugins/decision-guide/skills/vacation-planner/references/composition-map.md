# Composition map

## Fixed destination

`grilling` → canonical brief → `destination-area-planner` → `transport-comparison` → `hotel-comparison` → `itinerary-builder` → `trip-budget-planner` → `trip-verification` → `trip-site-publisher`.

## Open-ended discovery

`grilling` → canonical brief → `trip-opportunity-finder` → `trip-feasibility-checker` → diverse shortlist → transport/area/stay research → `itinerary-builder` → `trip-budget-planner` → deep verification of top finalists → `trip-site-publisher`.

Do not run every composed skill mechanically. Skip specialists irrelevant to the brief. Run expensive live verification only after broad screening has reduced the field.
