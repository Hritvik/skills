# Destination Area Planner

Compare candidate bases by access to priority experiences, driving/transit time, road quality, scenery, crowd level, restaurant access, arrival/departure logistics, and the traveller's vehicle access. Avoid repeatedly crossing the destination.

Recommend the smallest number of bases that produces a coherent trip. Add a base only when it materially improves experience or avoids excessive travel; account for the packing and check-in cost of moving.

Return the recommended base sequence, nights per base, decisive trade-off, rejected base patterns, and evidence IDs. Property selection belongs to `hotel-comparison`.
